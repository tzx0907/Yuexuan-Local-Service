# 悦选用户端前端

本目录用于统一管理“悦选本地到家服务平台”的用户端前端代码。

## 当前目录说明

- `legacy-mp-weixin/`：从课程资料中迁入的、可直接被微信开发者工具打开的小程序构建产物。原始 uni-app/Vue 源码在课程资料中缺失，因此该目录暂作为可运行基线，不能视为长期维护的源码。
- `yuexuan-miniprogram/`：后续重建的可维护 uni-app 源码工程。所有新的用户端功能、接口契约和悦选主题改造将优先沉淀到此目录。

## 当前运行方式

使用微信开发者工具导入 `legacy-mp-weixin/`。本地后端默认地址为 `http://localhost:8080`；真机调试不能访问电脑的 `localhost`，需要使用局域网 IP 或合法 HTTPS 域名。

## 迁移原则

不直接在 `legacy-mp-weixin/common/vendor.js` 中长期开发。后续会先建立源码目录，再逐页迁移“商品浏览、购物车、下单、支付、订单”主链路，同时对齐后端接口。
