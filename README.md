# fly-take-out

苍穹外卖后端项目，采用 Spring Boot 多模块结构，主要包含通用工具与异常模块、业务 POJO 模块和服务端接口模块。

## 模块结构

- `sky-common`：通用常量、异常、上下文、返回结果、JSON、JWT、HTTP、OSS、微信支付等公共能力。
- `sky-pojo`：DTO、Entity、VO 等业务数据对象。
- `sky-server`：后台管理接口、业务服务、Mapper、拦截器、全局异常处理和应用配置。
