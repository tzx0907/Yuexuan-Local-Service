# 微信真机联调：为什么手机没有数据，以及如何连接本机后端

## 根因

小程序此前请求地址是 `http://localhost:8080`。在微信开发者工具模拟器里，
`localhost` 指你的开发电脑；但在真机上，`localhost` 指**手机自己**，不是电脑，
所以手机无法请求到运行在电脑上的 Spring Boot 服务。

当前电脑 WLAN IPv4 为 `192.168.43.233`，小程序编译产物已改为：

```text
http://192.168.43.233:8080
```

## 真机调试步骤

1. 电脑和手机必须连接同一个 Wi-Fi / 同一手机热点；
2. 启动后端，确认电脑浏览器能访问 `http://localhost:8080/doc.html` 或已有健康/接口地址；
3. Windows 防火墙若弹出 Java 访问网络提示，选择“专用网络”允许；如果没有弹窗，需要放行 TCP 8080 入站规则；
4. 微信开发者工具中勾选“**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**”；局域网 HTTP 地址不能通过正式域名校验；
5. 重新编译小程序后使用“真机调试”；
6. 用手机浏览器访问 `http://192.168.43.233:8080`。能连通说明网络地址正确；若不能连通，先检查步骤 1 和 3。

## 换网络后的必要操作

局域网 IPv4 会随 Wi-Fi 或热点变化。电脑执行：

```powershell
ipconfig
```

找到当前网络适配器的 `IPv4 Address`，把
`frontend/legacy-mp-weixin/common/vendor.js` 中的 `baseUrl` 更新为：

```text
http://新的IPv4:8080
```

同时不要再在页面里写死 `localhost`；统一使用 `baseUrl`。本次已将订单成功页取消订单接口改为统一地址。

> 正式上线不能使用局域网 HTTP IP。应部署 HTTPS 后端，并在微信公众平台配置 request 合法域名。
